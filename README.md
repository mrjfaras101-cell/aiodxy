# موقع Aiodxy — الموقع الرسمي

🔗 **الموقع المباشر:** https://mrjfaras101-cell.github.io/aiodxy/

هذا المستودع يحمل شيئين: **الموقع الجاهز المنشور** في الجذر، و**المشروع الكامل** في مجلد `source`.

## ماذا يوجد هنا؟

| المكان | الوصف |
| --- | --- |
| ملفات الجذر: `index.html` · `assets/` · ملفات الشعار `logo-*.svg` · الصور · `og-image.png` | 🟢 **الموقع المنشور فعليًا** على الرابط أعلاه. هذه ملفات ناتجة عن البناء — لا تُعدّل باليد. |
| `source/` | 🔧 **مشروع الموقع الكامل** (React + TypeScript). كل التعديلات تُجرى هنا. |
| `source/src/i18n/content.ts` | كل نصوص الموقع وبيانات التواصل (عربي/إنجليزي) في ملف واحد. |
| `source/QUICK-START.txt` | دليل مختصر: التشغيل، النشر، أماكن التعديل. |
| `source/brand/` | ملف توليد الشعار + معاينة الهوية البصرية. |

## كيف أعدّل الموقع وأعيد نشره؟

```bash
# 1) عدّل النصوص في source/src/i18n/content.ts ثم جرّب محليًا
cd source
npm install
npm run dev            # http://localhost:5173

# 2) أنشئ نسخة جديدة
npm run build          # تُنتج مجلد source/dist

# 3) انسخ النسخة الجديدة إلى جذر المستودع وارفعها
cd ..
cp -r source/dist/. .
git add -A
git commit -m "تحديث الموقع"
git push
```

بعد الرفع يعيد GitHub Pages نشر الموقع تلقائيًا خلال دقيقة تقريبًا.
> يمكنك أيضًا أن تطلب من Arena أي تعديل، وسيتم تحديث الموقع ونشره تلقائيًا.
