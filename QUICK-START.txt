الحزمة الكاملة لموقع Aiodxy — شريك أودو / Aiodxy Odoo Partner Website
====================================================================

المحتوى:
  odoo-partner-site/            ملفات المشروع (الكود المصدري + الشعارات + البناء الجاهز)
    ├── src/                    كود الموقع (React + TypeScript) — كل النصوص في src/i18n/content.ts
    ├── public/                 الشعارات (SVG)، أيقونة الموقع، بطاقة المشاركة، صور الخلفيات
    ├── dist/                   ✅ نسخة إنتاجية مبنية وجاهزة — يمكن رفعها على أي استضافة فورًا
    ├── brand/                  ملف توليد الشعارات + معاينة الهوية (aiodxy-brand-preview.png)
    ├── index.html, package.json, vite.config.ts, tsconfig.json
    └── README.md               الشرح الكامل (التشغيل، التعديل، البنية)

════════════════════════════════════════════════════════════════
1) تشغيل الموقع على جهازك (للتطوير والتعديل)
════════════════════════════════════════════════════════════════
شغّل الأوامر التالية داخل مجلد odoo-partner-site:

    npm install        # تثبيت المكتبات (مرة واحدة، يحتاج إنترنت)
    npm run dev        # تشغيل نسخة التطوير على http://localhost:5173
    npm run build      # إنتاج نسخة النشر داخل مجلد dist/
    npm run brand      # إعادة توليد ملفات الشعار (اختياري)

يتطلب Node.js إصدار 20 أو أحدث.

════════════════════════════════════════════════════════════════
2) النشر بدون أي أدوات برمجية
════════════════════════════════════════════════════════════════
مجلد dist/ جاهز للنشر كما هو. ارفع محتوياته فقط (لا المجلد نفسه)
إلى أي استضافة ثابتة:

  • استضافة عادية (cPanel / FTP): ارفع محتوى dist إلى public_html
  • Netlify / Vercel / Cloudflare Pages: اسحب مجلد dist أو اربطه بمستودع git
  • GitHub Pages: ارفع محتوى dist على فرع gh-pages

ملاحظة: الموقع صفحة واحدة (لا يحتاج إعدادات توجيه خاصة).

════════════════════════════════════════════════════════════════
3) التعديلات التي تهمّك أولًا
════════════════════════════════════════════════════════════════
كل النصوص وبيانات التواصل في ملف واحد:
    odoo-partner-site/src/i18n/content.ts
      • أول كتلة siteConfig: الاسم، البريد، الهاتف، واتساب، العنوان، الساعات، السوشيال
      • copy.ar و copy.en: كل نصوص الموقع بالعربية والإنجليزية
      • appCategories: قائمة تطبيقات أودو المعروضة

الشعار:
      • داخل الموقع: src/components/ui/Logo.tsx
      • الملفات الجاهزة (فواتير، عروض، سوشال): public/logo-*.svg
      • إعادة التوليد بخطوة واحدة: npm run brand

الأرقام والأسعار: ابحث عن "60+" (عدد المشاريع) و"97%" (رضا العملاء)
و"4,900" (أسعار الباقات) في ملف content.ts وعدّلها لتطابق واقع شركتك.

آراء العملاء المعروضة حاليًا نماذج مبدئية — استبدلها بمراجع حقيقية
(يوجد تعليق يوضّح ذلك في src/sections/Testimonials.tsx).

════════════════════════════════════════════════════════════════
ملاحظات مهمة
════════════════════════════════════════════════════════════════
• الموقع ثنائي اللغة: زر (EN / ع) في الأعلى يبدّل اللغة والاتجاه (RTL/LTR) فورًا.
• نموذج التواصل يعمل حاليًا عبر فتح برنامج البريد (mailto). لربطه باستقبال
  فعلي على الخادم، راجع نهاية src/sections/Contact.tsx.
• جميع الرسومات والأيقونات مبنية SVG داخل المشروع — لا مكتبات خارجية،
  ولا أي طلبات على شبكات خارجية عند التشغيل.
• معلومات أودو (التطبيقات، النسخ، الأسعار) مستندة إلى odoo.com مع الإشارة
  للمصدر، وحدّثها عند تغيّر أسعار أودو.
• يوجد تنويه في التذييل يوضّح أن Odoo علامة تجارية لشركة Odoo S.A.
  وأن الموقع ليس الموقع الرسمي لأودو.
